# @squeekkit/sdk

Community TypeScript integration for the documented Squeekchain Sepolia graph. Build from this repository; no npm publication is claimed.

See the [SDK reference](../../docs/SDK.md), [compatibility report](../../docs/COMPATIBILITY.md) and root README. Public exports include `createSqueekKit`, `SqueekChain`, `SqueekApi`, `verifyDeployment`, `evaluateMerge`, published ABIs, formatting helpers and structured errors.
